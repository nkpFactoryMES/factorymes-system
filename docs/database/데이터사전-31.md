# 검증된 MES 31테이블 데이터사전

기준: `01_tables.sql` 및 `02_indexes.sql`에서 직접 추출. 아래 타입·NULL·PK/FK/UQ·CHECK·기본값은 실제 DDL 기준이며 34테이블 참고안 전체를 대체 적용하지 않고 사용자 승인된6개 보강만 반영했다. 설명은 업무 의미를 덧붙인 문서이며 DB COMMENT를 추가하지 않는다.

병합 전 Claude 검증: Oracle Free 23 / FREEPDB1, 테이블31·FK54·CHECK379·UQ19·INVALID0, DATE 수정 후 업무 규칙11건 기대 결과. 현재 병합본은 테이블31·컬럼355·FK53·UQ24·조건부 UNIQUE6을 정적으로 확인했으며 Oracle 재실행은 Claude 대기 상태다. 재검증 결과는 README 참조.

DDL SHA-256: `3490745d874651c420ecbbaf789845200bf67862ca41d12d76f9afa28582a625` (UTF-8 텍스트 기준).

NULL: N=NOT NULL 또는 PK에 의해 필수, Y=NULL 허용. 복합 PK/UQ는 개별 컬럼 유일성이 아니다. 조건부 UNIQUE 인덱스는 일반 UQ 제약과 별도다. 모든 시각 TIMESTAMP(6)는 앱이 UTC 의미를 지켜야 한다.

기준 갱신: 승인된 병합6개를 반영한 DDL에서 추출했다. BUSINESS_DATE는 Claude가 DATE로 버그 수정한 정의를 유지한다. 신규 무결성은 부모 복합 UQ·복합 FK·AI 채택 결과 UNIQUE·실적 요청 해시다. Oracle 병합 후 재검증 상태는 README를 참조한다.
